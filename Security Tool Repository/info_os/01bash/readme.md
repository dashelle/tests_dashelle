# system-info-collector

# info_os_bash.sh

Bash-скрипт для сбора базовой информации о системе и сохранения её в файл отчёта.

Скрипт работает на **Linux** и **macOS**, поддерживает выбор нужных параметров и может использоваться как утилита для диагностики.

---

## Возможности

Скрипт может собирать следующую информацию:

- имя хоста
- основной IPv4-адрес
- информацию об операционной системе
- информацию о процессоре
- информацию об оперативной памяти
- краткую информацию о сетевых интерфейсах
- информацию о текущем пользователе

Результат:
- сохраняется в файл
- одновременно выводится в терминал

---

## Требования

- Bash
- macOS или Linux
- На Linux требуется запуск от **root** (sudo)
