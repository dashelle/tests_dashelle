# system-info-collector

Bash-скрипт для сбора информации о системе (Linux / macOS)
и сохранения её в отчётный файл.

## Возможности

Скрипт собирает:

- имя хоста
- IP-адрес (IPv4)
- информацию об ОС
- данные CPU
- информацию о памяти
- сетевую конфигурацию
- информацию о текущем пользователе

Поддерживается вывод:
- в файл
- в терминал
(одновременно)

## Поддерживаемые ОС

- Linux
- macOS
